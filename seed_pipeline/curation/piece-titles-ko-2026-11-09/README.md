# 작품 한국어 제목 고치기 (2026-11-09)

한국어 제목 칸(`pieces.title`)에 원어 제목이 그대로 있던 작품(보이는 작품 9,203곡) 가운데, 갈래 낱말이 있거나 MusicBrainz 작품 갈래가 있는 2,700곡을 한국어 화면 제목으로 옮겼습니다. 나머지(영화·드라마 큐, 고유 제목)는 그대로 둡니다.

- 기준: `SPEC.md`. 데이터에 이미 있는 한국어 제목의 관례(연습곡·녹턴·「갈래 <원제>」·조성 표기 등)를 따릅니다.
- 번역: AI 에이전트가 250곡씩 한 줄씩 판정했습니다(`translate` 우리말로, `label` 「갈래 <원제>」, `keep` 그대로). 확신이 없으면 keep.
- 결과: `titles.tsv`. translate 1,773, label 330, keep 598. 백남준 「조작된 피아노를 위한 에튀드」는 손으로 「연습곡」으로 바꿨습니다.
- 마이그레이션: `gen_sql.py` → `migrations/202611090002_translate_piece_titles_ko.sql`. 지금 제목이 그때 본 원제와 같을 때만 바꿉니다(그사이 사람이 고쳤으면 그대로). 영어 제목 칸(`title_en`)은 건드리지 않습니다.

검색은 한국어·영어·원어로 다 되므로(`src/search_terms.rs`) 한국어 제목을 바꿔도 원제로 찾을 수 있습니다.
