# 작품 카탈로그 4차 확장 (2026-10-12, 자동)

1~3차는 작곡가마다 에이전트가 위키백과 작품 목록을 보고 판단했어요. 4차는 원어 seed 가 50개 넘게 남은 클래식 작곡가 53명을 **사람·에이전트 판단 없이 규칙으로** 다시 짰어요.
마이그레이션은 `migrations/202610120049` ~ `202610120101` 이에요. 영화·TV·게임 작곡가(베어 매크리리·니노 로타·버나드 허먼·요한 요한손·Terry Plumeri)와 재즈·앰비언트 쪽(David Chesky·Harold Budd)은 뺐어요.

## 규칙 (`auto/auto_catalog.py`)

- **작품**: MusicBrainz 에서 이 작곡가가 composer 인 work 중, 다른 work 의 part 가 아니고 편곡·다른 판·발췌·단편·리믹스 표시가 없는 것. part 는 MB parts 순서대로 두 겹까지. 같은 이름의 MB 중복 work 는 하나로 합쳐요.
- **제목**: 「Symphony no. 5 in C minor」 → 「교향곡 5번 C단조」, 「Quintet for Guitar and Strings」 → 「기타 5중주」처럼 갈래·번호·조성·편성을 옮겨요. 못 읽으면 원제를 두고, MB 갈래가 가곡·오페라·뮤지컬 등이면 「가곡 <원제>」 꼴이에요. 작품번호는 Op. 가 있으면 Op., 없으면 제목 맨 앞 번호.
- **seed**: MBID 가 작품이면 그 자리(제목을 위 꼴로 고치고 잠금), part 면 part 로 이어요. MBID 로 못 잇는 악장 seed(「… G. 338: II. Adagio」)는 제목의 작품번호와 로마 숫자 악장이 카탈로그 작품 하나와만 맞을 때 이어요. 편곡·다른 판·중복·리믹스 seed 는 `hidden_reason='catalog_unmatched'` 로 숨기고, 판단이 서지 않는 seed 는 그대로 보이게 둬요(`unreviewed`).
- **manual**: 제목·설명·링크는 바꾸지 않아요. 손으로 넣은 MBID 가 전혀 다른 work 를 가리키면 잇지 않아요(거슈윈 「피아노 협주곡 F장조」의 MBID 가 뮤지컬 <Crazy for You> 였어요). MBID 가 없으면 영어 제목 낱말이 같은 작품에 잇고 식별자는 더하지 않아요.
- 생성기 `gen_catalog.py` 는 3차 판에 두 가지를 더했어요: 숨길 seed 가 카탈로그 제목을 쥐고 있으면 그 seed 제목 뒤에 까닭을 붙여 자리를 비우고(예: 편곡판을 가리키는 seed 「Gymnopédies」 때문에 원곡을 못 넣는 일), `unreviewed` seed 는 숨기지 않아요.

## 다시 만들기

`auto/auto_catalog.py --composer-id <id> --slug <slug> --db <운영 읽기 덤프 폴더> --out <slug>` → `gen_catalog.py --seed-map` → `gen_catalog.py --hide-only`. 덤프 폴더에는 `pieces.tsv`(작품 + MBID 목록), `all_mbids_taken.tsv`, `composers.tsv`(MB artist id)가 있어야 해요. MB 응답은 `tools/fetch.py` 가 `cache/` 에 남겨요(커밋하지 않아요). 같은 입력이면 출력이 같아요.
