# 연주자 배너 사진 (2026-11-07)

연주자 화면 머리에 깔 가로로 긴 배너 사진을 위키미디어 공용(Wikimedia Commons)에서 골라 둔 목록이에요.
`banners.jsonl` 한 줄이 연주자 한 명이에요.

## 대상과 범위

- 대상: 공개 비교 작품에 주 연주자(`performance_credits.is_primary`)로 올라 있는 연주자 254명. 비교 작품 수가 많은 순서로 봤어요.
- 이번에 본 범위: 상위 125위까지 123명. 그 아래 131명은 아직 안 봤어요.
- 고른 수: 55명. 비운 수: 68명.

## 고른 기준

- 라이선스: CC0, Public domain, CC BY, CC BY-SA 만. NC·ND·공정 이용·출처 불명은 뺐어요.
- 크기: 가로가 1280px 이상이고 가로/세로가 1.3 이상인 가로 사진.
- 그 연주자가 사진의 분명한 주인공이고 얼굴이 보여야 해요. 기념패·포스터·건물·무덤·동상·동명이인, 누가 누군지 모를 단체 사진은 뺐어요.
- 다른 사람이 같은 크기로 함께 나온 사진(예: 지휘자와 나란히 선 협연자)은 이름을 얹었을 때 헷갈려서 뺐어요.
- 자막·큰 글자가 얼굴 가까이 박힌 사진은 뺐어요.
- 후보 썸네일을 직접 보고 골랐어요. 맞는 사진이 없으면 비웠어요.

## 후보를 모은 방법

1. 위키데이터에서 이름을 찾아 음악가 설명이 붙은 항목을 고른 뒤 대표 그림(P18)과 공용 분류(P373)를 읽었어요.
2. 그 분류(하위 분류 6개까지)의 파일과 공용 검색 `filetype:bitmap "이름"` 결과를 모았어요.
3. 크기·라이선스로 거르고, 제목에 생가·무덤·기념패·포스터 같은 말이 든 파일을 뺀 뒤 연주자마다 16개까지 남겨 격자로 보고 골랐어요.
4. 요청은 순서대로 0.4초 간격, User-Agent `ClassicMapBannerCuration/0.1 (kang3171611@naver.com)`.

## 칸 설명

| 칸 | 뜻 |
|---|---|
| `artistId` | `artists.id` |
| `name` | 화면 이름 |
| `fileUrl` | 공용 원본 파일 주소 (upload.wikimedia.org) |
| `displayUrl` | 폭 1920 미리보기 주소. 원본이 1920보다 작으면 원본과 같아요. TIFF 원본(427 무티, 216 마이스키)은 브라우저가 못 그려서 이 주소를 써야 해요 |
| `sourceUrl` | 공용 파일 설명 페이지. 출처 표기 링크로 써요 |
| `author` | 지은이 (태그를 걷은 평문) |
| `license`, `licenseUrl` | 라이선스 이름과 주소. Public domain 은 주소가 없어 `null` 이에요 |
| `width`, `height` | 원본 크기 |
| `focalPoint` | CSS `object-position`. 데스크톱 1180×380(약 3.1:1)과 모바일 약 1.15:1 로 잘라 봤을 때 얼굴이 들어오게 맞췄어요 |
| `note` | 사진에 무엇이 있는지 짧게 |
