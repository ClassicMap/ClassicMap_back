# 남은 얼굴·배너 빈칸 채우기 2차 (2026-11-11)

`../entity-images-2026-11-10/`, `../s-artist-banners-2026-11-10/` 뒤에도 남은 빈칸을 넓힌 기준으로 채운 목록이에요.
사용자가 "어떻게든 채우라"고 해서 기준을 넓혔어요. 틀린 사람 그림은 여전히 넣지 않아요.

## 대상과 순서

1. 얼굴 그림이 하나도 없는 숨기지 않은 작곡가(115명) → 얼굴 그림(`composers.avatar_url`·`cover_image_url`).
2. 얼굴 그림(`artists.image_url`)이 없는 A·B 연주자(A 58, B 244) → 얼굴 그림. 기존 연주자 얼굴과 같은 칸이에요.
3. 배너가 없는 A 연주자 → 배너. 1·2를 거의 끝낸 뒤에만.

## 넓힌 기준

- 얼굴 그림은 짧은 변 400px 이상이면 써요. 그림·판화·옛 사진도 돼요.
- 단체 사진은 그 사람을 알아볼 수 있고, 가운데 정사각으로 잘랐을 때 그 사람이 가운데 오면 써요(앱은 얼굴을 가운데 정사각·원으로 잘라요).
- 자유 라이선스가 아닌 그림도 써요. 출처는 `entity_images`(`profile`) 의 `credit_line`·`source_url` 에 남겨요.

## 지킨 것

- 같은 사람인지: 이름 + 분야·시대 + 다른 단서 하나 이상(출처 페이지가 그 사람에 대한 것, 생몰년, 작품, 소속 등).
- 핫링크: 쿠키 없이 일반 브라우저 UA, `Referer: https://kang1027.com/` 으로 200·image 가 나오는 주소만 써요.
- 만료되는 서명 주소(페이스북·인스타그램 CDN 등)는 쓰지 않아요.
- 빈칸일 때만 넣어요.
