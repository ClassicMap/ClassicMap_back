## 넓힌 기준

- 작곡가 얼굴은 짧은 변 400px, 연주자 얼굴은 300px 이상이면 써요. 그림·판화·옛 사진도 돼요.
- 배너는 폭 1000px 안팎을 기본으로 하되, 다른 사진이 없으면 그보다 작아도 썼어요.
- 단체 사진은 그 사람을 알아볼 수 있고, 가운데 정사각으로 잘랐을 때 그 사람이 가운데 오면 써요(앱은 얼굴을 가운데 정사각·원으로 잘라요).
- 자유 라이선스가 아닌 그림도 써요. 출처는 `entity_images` 의 `credit_line`·`source_url` 에 남겨요.

## 지킨 것

- 같은 사람인지: 이름 + 분야·시대 + 다른 단서 하나 이상(출처 페이지가 그 사람에 대한 것, 생몰년, 작품, 소속, 위키데이터 연결 등).
- Discogs 그림만 있는 연주자는 위키데이터(P1953)로 같은 사람에 연결된 Discogs 항목일 때만 썼어요.
- 핫링크: 쿠키 없이 일반 브라우저 UA, `Referer: https://kang1027.com/` 으로 200·image 가 나오는 주소만 써요.
  위키미디어는 이 컴퓨터에서 요청이 몰리면 브라우저 UA 에 429 를 돌려줘서, 연락처 UA 로 천천히 확인했어요.
- 만료되는 서명 주소(페이스북·인스타그램 CDN 등)와 http 주소는 쓰지 않아요.
- 빈칸일 때만 넣어요. 얼굴은 `image_url`(작곡가는 `avatar_url`·`cover_image_url`)이 비었을 때, 배너는 공개 배너가 없을 때만이에요.
- 권리자가 요청하면 얼굴 칸을 비우거나 배너를 `RETIRED` 로 내려요.
