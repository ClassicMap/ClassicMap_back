# 작곡가·연주자 배너 더 채우기 (2026-11-08)

스포티파이 아티스트 머리 그림(`entity-banners-spotify-2026-11-07/`)이 없던 작곡가·연주자에게 다른 곳의 배너를 넣은 목록이에요.
`banners.jsonl` 한 줄이 한 사람이에요. `gen_sql.py` 가 `migrations/202611082001_fill_more_entity_banners.sql` 을 만들어요.

## 대상

- 11/7 작업 뒤에도 공개 배너가 없던 433명: 비교 연주자 96명, 작곡가 337명(S 4, A 16, B 310, C 7).
- 이미 배너가 있는 사람은 건드리지 않아요.

## 출처와 고른 순서

1. 애플 뮤직 아티스트 머리 그림(`wideArtwork`, 4320×2160)
   - 애플 뮤직 클래식이 작곡가마다 그린 초상이 대부분이고 품질이 가장 좋아요.
   - 2880×1440 webp 로 받아요.
   - 이름 첫 글자만 있는 글자 로고 그림은 뺐어요(아래 목록).
2. 애플 뮤직 아티스트 프로필(정사각 1200px 이상)
   - 얼굴이 작게 찍혀 3.2:1 로 잘라도 얼굴이 다 들어오는 것만 썼어요.
   - 얼굴을 가까이 찍은 사진은 눈이나 이마가 잘려서 뺐어요.
3. 유튜브 뮤직 아티스트 머리 그림
   - 공식 채널이 아닌 곳은 음반 표지가 그대로 나와서, 그 사람 사진이 분명한 것만 썼어요.
4. 위키미디어 공용
   - 연주자: 공용 분류에서 가로 사진(폭 1280px 이상, 가로/세로 1.3 이상)을 찾았어요. 고른 기준은 `artist-banners-2026-11-07/README.md` 와 같아요.
   - 작곡가: 위키데이터 대표 그림(P18)이 폭 900px 이상이고 3.2:1 로 잘라도 얼굴이 다 들어오는 것만 썼어요.
   - 사진이 하나도 없던 작곡가에 한해 찾았어요.
   - 라이선스는 Public domain, CC0, CC BY, CC BY-SA 만 써요. 지은이·라이선스는 화면에 그대로 보여요.

## 아이디 찾기

- 애플 뮤직: 위키데이터 P2850 이 있으면 그걸 썼어요.
  - 없으면 iTunes 검색 API 결과 중 이름이 정확히 같은 것만 썼어요. 악센트·대소문자·문장부호는 무시하고, 위키데이터 여러 언어 이름·별칭과 비교했어요.
- 유튜브 뮤직: 아티스트 검색 결과 중 이름이 정확히 같은 첫 채널을 썼어요.
- 모든 그림은 데스크톱 3.2:1 과 모바일 1.15:1 로 잘라 격자로 직접 보고 골랐어요.
