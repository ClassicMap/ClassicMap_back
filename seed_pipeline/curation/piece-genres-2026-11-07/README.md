# 비교 작품 장르 2026-11-07

비교 구간이 있는 작품 257곡의 장르다. 결과는 `genres.jsonl` 이고, `gen_sql.py` 가
`migrations/202611072002_fill_comparison_piece_genres.sql` 로 바꾼다. 화면은 작품 카드의
색·커버와 장르 필터에 쓴다(`/comparison-pieces?genre=`).

## 값

| 키 | 이름 | 넣는 곡 |
|---|---|---|
| `symphony` | 교향곡 | 교향곡(합창 교향곡 포함) |
| `concerto` | 협주곡 | 협주곡과 협주풍 작품(사계, 랩소디 인 블루, 파가니니 랩소디, 신포니아 콘체르탄테, 서주와 론도 카프리치오소) |
| `piano` | 피아노 | 건반 독주(하프시코드·피아노 연탄·두 대의 피아노 포함) |
| `chamber` | 실내악 | 실내악과 건반 아닌 독주(무반주 첼로, 바이올린 소나타, 현악 4중주) |
| `orchestral` | 관현악 | 교향곡·협주곡이 아닌 관현악(교향시, 연주회용 서곡, 관현악 모음곡, 세레나데, 부수음악) |
| `stage` | 오페라·발레 | 오페라·오페레타·발레와 그 발췌(오페라 서곡·아리아·합창·무곡 포함) |
| `vocal` | 성악 | 가곡·연가곡·합창·종교곡(미사, 레퀴엠, 오라토리오, 칸타타, 모테트, 마니피카트) |

## 기준

- 원곡 편성으로 정한다. 비교 연주가 모두 굳은 편곡판으로 도는 곡만 그 편성을 따른다(헝가리 무곡 5번, 정화된 밤, 어미 거위 → 관현악. 난 그대를 원해요 → 피아노)
- 오페라·오페레타 서곡과 관현악 대목(발퀴레의 기행, 정령들의 춤)은 오페라 발췌로 본다
- 연극 부수음악(한여름 밤의 꿈, 페르 귄트, 가면무도회)은 관현악으로 본다
- 판단 근거는 줄마다 `note` 에 적었다

## 고칠 때

`genres.jsonl` 을 고치고 `python3 gen_sql.py` 로 새 날짜의 마이그레이션을 만든다.
이미 적용된 마이그레이션 파일은 고치지 않는다. 새 비교 작품을 넣을 때도 이 파일에 줄을 더하고 같은 방식으로 채운다.
