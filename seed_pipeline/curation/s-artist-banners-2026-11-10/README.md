# S 연주자 배너 마저 채우기 (2026-11-10)

`../entity-images-2026-11-10/` 뒤에도 공개 배너가 없던 S 연주자 14명에게 화면 머리 배너를 넣은 목록이에요.
스포티파이·애플 뮤직·위키미디어에 쓸 그림이 없던 사람들이라, 사용자가 저작권 위험을 감수하고
공식 사이트·음반사·대행사·공연장 페이지의 보도용 사진과 뉴스 사진도 쓰기로 했어요.

## 고른 기준

- 그 사람(단체)이 분명한 사진이어야 해요. 단체는 단체 사진이나 무대 연주 사진이면 돼요.
- 얼굴이 잘리지 않고, 로고·광고 글자가 없어야 해요.
- 데스크톱(3.2:1)·모바일(1.15:1)로 잘라 본 격자로 초점(`focal_point`)을 정했어요.
- 앱은 사용자 브라우저에서 그림 주소를 바로 불러요. 그래서 넣는 주소는 쿠키 없이 일반 브라우저 UA,
  `Referer: https://kang1027.com/` 으로 200·image 가 나오는 것만 썼어요. 대기열·401·403 으로 막는 주소는 뺐어요.
- 봇 차단으로 못 본 페이지(metopera.org 대기열, pizzicato.lu 429 등)는 사용자 브라우저(Aside)로 열어 봤어요.
- 못 찾으면 빈칸으로 둬요.

## 넣는 곳

`202611100104_fill_s_artist_banners.sql` 이 `entity_images`(`banner`, `PUBLISHED`)에 넣어요.

- 공개 배너가 하나도 없을 때만 넣어요.
- `credit_line` 은 출처 이름(아는 경우 사진가), `source_url` 은 출처 페이지예요. 화면에 "사진: {credit_line}" 으로 보이고 누르면 출처 페이지가 열려요.
- 그림은 출처 서버를 그대로 가리켜요. 권리자가 요청하면 그 줄을 `RETIRED` 로 내려요.

## 다시 만들기

```bash
cd seed_pipeline
uv run python curation/s-artist-banners-2026-11-10/gen_sql.py
```

- `raw/pages.tsv`: 본 페이지 목록. `raw/candidates.jsonl`: 거기서 받은 가로 그림 후보(폭 1000px 이상, 가로/세로 1.2 이상).
- `collect/page_images.mjs`: 페이지를 playwright WebKit 으로 열어 그림을 모으는 스크립트. 초점 계산은 `../entity-images-2026-11-10/collect/` 의 `faces.swift`·`focal.py` 를 같이 써요.
- Aside 로 본 페이지와 그림 주소는 `raw/aside-pages.jsonl` 에 있어요.
