# 작품 카탈로그 5차 확장 (2026-11-07, 자동)

4차 규칙(`../catalog-wave4-2026-10-12/auto/auto_catalog.py`, 생성기 `../catalog-wave4-2026-10-12/gen_catalog.py`)을 고치지 않고 그대로 썼어요. 대상은 원어 seed 가 아직 20개 넘게 남은 클래식 작곡가 36명이에요(`composers.txt`).
마이그레이션은 `migrations/202611070101` ~ `202611070136` 이에요.

- 고른 기준: 운영 DB 에서 보이는 작곡가 중, 잠기지 않고 숨기지 않았고 part 로도 이어지지 않은 seed 작품이 20개 넘는 작곡가.
- 뺀 작곡가: 1~4차에서 이미 다룬 작곡가(남은 seed 는 4차가 판단을 못 한 `unreviewed`), 영화·TV·게임·애니·앰비언트 쪽(베어 매크리리·니노 로타·버나드 허먼·Terry Plumeri·요한 요한손·David Chesky·해럴드 버드·Mina Kubota·사에구사 시게아키). 이쪽은 숨길지 따로 정해요.
- Antonio de Cabezahueca 는 MusicBrainz 의 작곡가 이름 그대로예요. seed 제목은 안토니오 데 카베손의 건반 작품(티엔토·디페렌시아스 등)이에요.

## 다시 만들기

4차 README 의 순서와 같아요. 운영 읽기 덤프(`pieces.tsv`·`all_mbids_taken.tsv`·`composers.tsv`)를 받은 뒤 `composers.txt` 의 작곡가마다

`auto_catalog.py --composer-id <id> --slug <slug> --db <덤프 폴더> --out <slug>` → `gen_catalog.py --seed-map` → `gen_catalog.py --hide-only`

를 돌리고, 작곡가마다 머리 주석 + 카탈로그 SQL + 숨김 SQL 을 한 마이그레이션으로 묶어요. 작곡가별 `composers.tsv` 의 `mb_artist` 는 `external_identifiers`(namespace `musicbrainz_artist`)에서 읽어요.
