# 작품 카탈로그 3차 확장 (2026-10-12)

국제 시드가 원어 제목으로 작품을 수백~수천 개 넣어 둔 작곡가 12명을 출판 단위 묶음과 그 안의 곡으로 다시 짠 자료예요.
1·2차(`../catalog-wave1-2026-10-11`, `../catalog-wave2-2026-10-12`)는 새 작품을 넣는 일이었고, 3차는 이미 있는 seed 작품을 카탈로그에 맞추는 일이 핵심이에요.
마이그레이션은 `migrations/202610120036` ~ `202610120047` 이고, 본문은 이 폴더의 `gen_catalog.py`(1·2차 생성기에 seed 대응을 더한 판)로 만들었어요.
숨김 칼럼(`hidden_reason`)과 목록 필터는 `202610120035` 와 `docs/catalog-hidden.md` 에 있어요.

- `SPEC.md`: 에이전트에게 준 작업 명세예요. 2차 명세에 「기존 시드 작품 대응」(seed_map.json 꼴, unmatched 까닭, `excerpt_keep`)을 더했어요.
- `<작곡가>/catalog.json`: 카탈로그 작품. `<작곡가>/seed_map.json`: 그 작곡가 seed 작품마다 `work`(카탈로그 작품 자리) / `part`(묶음·다악장 안 곡) / `unmatched`(까닭과 근거) 대응이에요. 바흐는 성악(`bach-vocal`)과 기악(`bach-instr`)으로 나눠 짰고, 두 seed_map 을 합치면 바흐 seed 1,686개를 겹침 없이 덮어요.
- `<작곡가>/report.md`: 운영 기존 작품 대응, 뺀 것과 까닭, 애매했던 판단, 직접 옮긴 우리말 이름, 위키백과 대조 결과예요. 일부는 에이전트가 메시지로 보낸 본문을 옮긴 것이에요(에이전트 쪽에서 보고서 파일 쓰기가 막혀 있었어요).
- `gen_catalog.py`: `--seed-map` 을 주면 seed 작품을 카탈로그 제목으로 고치고(`editor_locked=0` 인 것만), part 로 이은 seed 는 「<작품> 중 "<곡>"」 꼴로 바꿔요. `--hide-only` 는 seed_map 에서 work/part/`excerpt_keep` 이 아닌 seed 를 `hidden_reason='catalog_unmatched'` 로 숨기는 SQL 을 만들어요. 비교 구간이 있거나 part 가 가리키는 작품은 숨기지 않고, seed_map 에 빠진 seed 가 있으면 숨김 SQL 을 만들지 않아요.
