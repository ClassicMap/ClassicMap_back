## 360 의 role 을 ENSEMBLE 에서 SOLOIST 로 바꿨다

배치 정의는 `ENSEMBLE` 이었다. **이 곡의 이름 붙은 앙상블 녹음이 여섯인데 위키데이터
항목이 하나도 없다.**

| 앙상블 | 영상 | 배급 |
|---|---|---|
| Tashi | `f1JQN65kONY` | RCA Red Seal |
| Ensemble Walter Boeykens | `MNgcSLvNFHs` | PIAS |
| Amici Ensemble | `TZA1-R6BwFo` | NAXOS of America |
| Zurich Ensemble | `rNgn1Y5B79I` | NAXOS of America |
| Left Coast Chamber Ensemble | `MSXcWxGWzLU` | The Orchard |
| Eurythmia Quartet | `_SJAkuTtWTc` | NAXOS of America |

적재기는 연주자를 `external_identifiers.wikidata` 로만 해소하므로 쓸 수 없다.

낱 연주자를 앞세운 판을 쓰려니 **앞선 악기가 갈렸다** — 샤함은 바이올린, 프뢰스트와
크라카워는 클라리넷, 에셴바흐는 피아노다. 하나의 `role` 로 덮을 수 없어 보였는데
적재기를 읽어 보니 길이 있었다.

```rust
// src/comparison_seed_loader.rs  canonical_credit_role
"PIANIST" | "VIOLINIST" | … | "CLARINETIST" | … | "SOLOIST" => Ok("soloist"),
```

**`SOLOIST` 를 그대로 받는다.** 악기별 독주자는 어차피 DB 에서 `soloist` 하나로 묶이고
`artists.category` 는 등록 때 각자 제 악기로 들어간다. **이름 붙은 앙상블이 없는
실내악은 `SOLOIST` 로 적으면 악기를 속이지 않고 첫 크레딧을 쓸 수 있다.**

## 360 에서 포펜을 크라카워로 바꿨다

처음 편성은 샤함 · 포펜 · 프뢰스트였고 **샤함↔포펜 한 쌍만 0.1176 으로 임계를 넘었다.**
에셴바흐와 크라카워를 예비로 받아 다섯 연주 열 쌍을 다 쟀다.

| 쌍 | 비용 |
|---|---|
| 프뢰스트 ↔ 크라카워 | 0.0731 |
| 포펜 ↔ 크라카워 | 0.0978 |
| 샤함 ↔ 프뢰스트 | 0.0995 |
| 포펜 ↔ 프뢰스트 | 0.1005 |
| 에셴바흐 ↔ 크라카워 | 0.1020 |
| 샤함 ↔ 크라카워 | 0.1028 |
| 포펜 ↔ 에셴바흐 | 0.1140 |
| 샤함 ↔ 에셴바흐 | 0.1144 |
| 프뢰스트 ↔ 에셴바흐 | 0.1173 |
| 샤함 ↔ 포펜 | 0.1176 |

조합 열 가지 가운데 **포펜·프뢰스트·크라카워가 0.1005 로 가장 낮고 샤함·프뢰스트·
크라카워가 0.1028 로 다음**인데 차이가 0.0023 으로 잡음이다. **더 알려진 샤함**
(DG, 폴 메이어·왕젠·정명훈과의 판)을 남겼다. 에셴바흐는 어느 조합에서도 0.1140 이상이라
쓰지 않았다.

검출값으로 다시 재니 0.0696 / 0.0995 / 0.1007 이 됐다(예비 견줄 때는 파일 길이에서
어림한 구간이었다).

## 354 의 길이가 2.37배 갈린다

유자 왕 159초 · 올라프손 255초 · 휘트웰 377초다. 글래스 연습곡은 메트로놈 지시가 있어도
연주자마다 크게 갈린다. **전곡이라 발췌 압축 판별이 해당하지 않는다.** 근거를 회전과
교차 정렬에 두었다.

자기 정렬이 0.088~0.129 로 낮은 편이다(되풀이 음형이라 자리를 덜 가린다). **구간이
전곡이라 자리가 구조로 고정돼 있어** A20 볼레로처럼 자리를 의심할 필요가 없다.
