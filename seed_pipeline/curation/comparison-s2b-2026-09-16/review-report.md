# 비교 영상 S2 둘째 배치 검수 보고서

## 결론

쇼팽 소품 3곡에 연주 3종씩, 총 9개 후보를 적재했습니다. 방식은 [첫 배치](../comparison-s2-2026-09-16/review-report.md)와 같습니다. 곡이 짧아 작품 전체가 곧 구간이므로, 음악이 실제로 시작하고 끝나는 지점만 오디오에서 찾았습니다.

| 곡 | 연주 3종 | 구간 |
|---|---|---|
| 전주곡 Op.28 No.15 "빗방울" | 랑랑 / 조성진 / 호로비츠 | 2–389 / 2–301 / 1–290초 |
| 연습곡 Op.10 No.3 "이별의 곡" | 폴리니 / 임윤찬 / 시시킨 | 1–211 / 1–243 / 0–257초 |
| 폴로네즈 Op.53 "영웅" | 조성진 / 키신 / 호로비츠 | 5–413 / 5–328 / 12–412초 |

## 교차 정렬 검증이 한 건을 걸러냈습니다

이별의 곡에 처음 넣으려던 연주는 다른 두 연주와 정렬 비용이 0.1325~0.1340으로 높았습니다. 나머지 두 연주끼리는 0.0469로 잘 맞았으므로 그 하나만 어긋난 경우입니다.

원인을 세 갈래로 좁혔습니다.

- **피치 차이 아님** — 12방향으로 돌려도 나아지지 않았습니다
- **구간 경계 문제 아님** — 구간을 앞·중간·뒤로 나누면 각각 0.045 / 0.072 / 0.109로 나쁘지 않았습니다
- **재정렬로도 해결 안 됨** — 잘 맞는 연주를 기준으로 구간을 다시 잡아도 0.132로 그대로였습니다

같은 곡의 다른 판본으로 보고 교체했습니다. 교체한 연주(시시킨, Chopin Institute)는 0.0447~0.0550으로 통과했습니다.

## 길이만으로는 판정할 수 없습니다

반대 사례도 나왔습니다. 빗방울 전주곡은 세 연주의 길이가 288~386초로 **1.34배** 차이 납니다. 길이만 보면 의심스럽지만 정렬 비용은 0.0660~0.0735로 문제가 없었습니다. 영웅 폴로네즈도 1.26배 차이에 0.0595~0.0794였습니다.

길이 편차는 연주자의 템포 선택일 뿐이고, 같은 악보 구간인지는 화성 진행으로만 판정됩니다.

## 작품 식별자

세 곡 모두 낱곡 work 를 씁니다. 빗방울과 이별의 곡은 검색으로 낱곡이 바로 걸리지 않아 모음곡 부모(24 Préludes op.28, Études op.10)의 하위 작품에서 찾았습니다. 영웅 폴로네즈는 같은 제목의 work 가 셋 있어 연결된 녹음이 351건인 것을 골랐습니다(나머지는 1건 이하).
