## 기존 작품

- 운영 작품 대부분이 MBID 가 없고 제목이 옛 꼴(「소나타 D단조」·「오르페오」)이에요. gen_catalog 의 MBID·제목 검사로는 같은 작품을 다시 넣는 걸 못 막아서,
  `build.py` 가 existing 칸이 빈 줄의 작품번호를 같은 작곡가 운영 작품의 작품번호(`Kk. 141 (L. 422)` → `K 141`, `Z 626`, `TWV 51:G9` 등)와 맞춰 보고 겹치면 멈춰요.
- 기존 작품은 `existingPieceId` 로 이어요. 제목·설명·링크·장르는 바꾸지 않고 MBID 와 곡만 더해요(타펠무지크 18곡, 파리 4중주 12곡, 저녁기도 14곡, 메리 여왕의 장례식 음악 7곡 등).
- 몬테베르디 「님프의 탄식」(19)은 마드리갈 8권 안 곡(SV 163)으로 이어서 작곡가 화면 최상위에서는 빠져요(코렐리 크리스마스 협주곡·라 폴리아와 같은 방식). 「처음 듣는다면」 카드는 piece_id 로 그대로 보여요.
- 퍼셀 「디도의 탄식」(35)은 오페라 대목이라 손대지 않았어요(오페라는 곡 없이 낱곡).
- 「처음 듣는다면」 카드·비교 구간은 바뀌지 않아요(시험 DB 에서 전후 체크섬 같음).

## 이름 규칙

- 제목은 운영 관례(바흐·헨델·비발디)를 따랐어요: 「오페라 <울리세의 귀환>」, 「부수음악 <암피트리온>」, 「송가 <Hail, bright Cecilia>」, 「3성부 소나타 Z 790–801」, 「건반 소나타 D단조 K. 141」.
  텔레만은 같은 조성 작품이 많아 새 작품 제목 끝에 TWV 를 붙였어요(「트럼펫 협주곡 D장조 TWV 51:D7」, 「관현악 모음곡 C장조 "수상 음악" TWV 55:C3」).
- 널리 쓰는 우리말이 없는 연극·송가 제목은 원제로 뒀어요(「부수음악 <The Married Beau>」, 「송가 <Who can from joy refrain?>」).
- 곡 이름은 MB 원제. 묶음 안 곡이 갈래·조성뿐이면 조성만(「A장조」), 갈래가 섞이면 「협주곡 D장조」. 손으로 엮은 묶음은 parts.tsv 에 우리말로 적었어요(「서곡 E단조 (1부)」, 「판타지아 D단조 (3성부)」).
- 몬테베르디 묶음 곡 순서·SV 번호는 영어 위키백과 「List of compositions by Claudio Monteverdi」 세부 표(Stattkus 목록)를 따르고, MB 곡은 SV 번호로 찾았어요. 다른 판(SV 257a·197a)은 뺐고,
  위키백과 표에 빠진 SV 195 「Beatus vir」를 <미사와 시편>에 넣었어요.
- 연도는 확실할 때만(묶음은 출판 연도). 퍼셀은 영어 위키백과 작품 목록의 Z 번호별 연도, 몬테베르디는 같은 목록의 SV 번호별 연도와 맞춰 보고
  다르거나 범위인 곳(퍼셀 Z 19·335·370·379·577·607 등)은 비웠어요. 장르·형식은 piece_forms 짝만 쓰고(생성기가 검사), 비어 있을 때만 채워요.

## build.py 가 슈트라우스 때와 다른 점

- works.tsv 칸: MBID 앞 8자(손으로 엮은 묶음은 이름), 제목, 작품번호, 연도, genre, form_key, kind(single·multi·coll), 운영 작품 id, parts(-·mb·file), 영어 제목(MB 작품이 없을 때).
- parts.tsv 칸: 묶음 key, 곡 MBID 앞 8자(없으면 -), 이름, 이어 붙일 운영 작품 id, 악장(mb·-).
- 묶음 안 곡의 악장(children)까지 두 겹을 붙여요. 세 겹인 MB(타펠무지크: 3부 → 6곡 → 악장)는 parts.tsv 로 두 겹으로 폈어요.
- `TWV 43:G1`·`SV 154:3` 처럼 쌍점이 든 번호 때문에 곡 이름은 묶음 이름을 앞에서 떼고 「: 」(쌍점+빈칸)으로만 잘라요.
- MB 에 순서(ordering-key·제목 번호·SV 번호)가 없는 곡이 있거나, 한 작품 안에서 순서 출처가 섞이면 제목 순으로 늘어놓지 않고 멈춰요. 그런 작품(퍼셀 송가 6개·예배곡, 텔레만 「민족들」 모음곡)은 곡 없이 낱곡으로 뒀어요.
- 같은 자리에 두 벌 걸린 MB 곡은 하나만 쓰고 표준 오류로 알려요. 악장 번호는 MB 제목 번호가 겹치거나 빠진 곳이 있어 순서대로 붙여요.

## 다시 만들기

`seed_pipeline` 에서:

1. 덤프: `curation/catalog-wave6-2026-11-10/tools/dump.sh <덤프>`
2. 작곡가마다: `uv run python curation/baroque-catalog-2026-11-12/build.py --composer telemann --db <덤프> --out <작업 폴더> --migration ../migrations/202611120101_add_telemann_catalog.sql`
   (purcell → 0102, scarlatti → 0103, monteverdi → 0104). gen_catalog 까지 돌려 머리 설명(`<작곡가>/header.sql`) + catalog.sql + 장르·형식을 써요.

MusicBrainz 요청은 `../catalog-wave6-2026-11-10/tools/fetch.py`(캐시·1.1초 간격)로만 보내요. 같은 덤프·캐시면 출력이 같아요(바이트 단위로 확인).
