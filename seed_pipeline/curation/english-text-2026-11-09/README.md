## 만든 방법
1. `export.py`: 시험 DB 에서 한국어 원문과 문맥(영어 이름·제목)을 `in/*.jsonl` 로 받습니다.
2. 13묶음(`out/` 파일 이름의 A~K)으로 나눠 AI 에이전트가 `SPEC.md` 기준으로 옮겼습니다. 사람 이름은 DB 의 한·영 이름 대조로 맞췄습니다.
3. `validate.py`: id·순서, 빠진 칸, 한글 남음, 길이 제한을 확인합니다.
4. `gen_sql.py`: 한국어 원문의 SHA-256 이 그때와 같을 때만 영어를 넣는 마이그레이션을 만듭니다. 원문을 고치면 그 칸의 영어는 들어가지 않으니 다시 옮겨야 합니다.
