# 작곡가·연주자 화면 머리 배너 — 스포티파이 아티스트 머리 그림 (2026-11-07)

화면 머리 배너를 스포티파이 아티스트 화면의 머리 그림(2660×1140 등 가로 그림)으로 채운다.
위키미디어 자유 라이선스 사진(`../artist-banners-2026-11-07/`)만으로는 50명에 그쳐서, 사용자가
저작권 위험을 알고 화질 좋은 그림을 쓰기로 정했다.

## 조건
- 출처는 화면에 "사진: Spotify" 로 밝히고, 누르면 그 사람의 스포티파이 아티스트 페이지가 열린다.
- 권리자가 내려 달라고 하면 그 행의 `editorial_status` 를 `RETIRED` 로 바꾼다(지우지 않는다).
- 그림은 스포티파이 그림 서버(`i.scdn.co/image/<hash>`)를 그대로 가리킨다. 우리 서버에 복사하지 않는다.

## 만든 방법
1. 대상: 비교 화면에 주 연주자로 나오는 연주자 254명 + 숨기지 않은 작곡가 408명.
2. 스포티파이 아티스트 id: 위키데이터 P1902 로 330명, 없는 사람은 스포티파이 검색 첫 결과 중 이름이 같은 것으로 148명.
3. 아티스트 웹 페이지가 부르는 응답에서 머리 그림(가장 큰 크기)을 받았다. 머리 그림이 없는 사람은 뺀다.
4. 그림마다 macOS Vision 으로 얼굴(없으면 상반신)을 찾아 초점을 정했다. 넓은 화면(약 3.2:1)은 위아래가,
   좁은 화면(1.15:1)은 좌우가 잘리므로 세로 값은 넓은 화면, 가로 값은 좁은 화면 기준이다.
5. 넓은 화면·좁은 화면으로 자른 확인 격자를 한 장씩 눈으로 보고 뺄 것과 초점을 고친 것을 정했다.

## 뺀 것
- 광고 글자가 큰 그림: 르네 플레밍(앨범 제목), 글렌 굴드(골드베르크 음반 문구), 데이비드 크라카워(이름 로고).
- 사람이 없는 그림: 카렐 크라이엔호프(반도네온만).
- 동명이인: 작곡가 에밀 뒤랑(다른 음악가의 그래픽 그림), 작곡가 제임스 윌슨(아기 곰 그림).
- 위키미디어 배너가 더 나은 것: 힐러리 한(스포티파이 그림은 얼굴이 흔들려 흐림).

같은 사람에게 위키미디어 배너가 이미 있으면 그건 대표에서 내리고(지우지 않음) 스포티파이 그림을 대표로 둔다.
