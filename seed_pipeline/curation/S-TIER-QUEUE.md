# S tier 적재 대기열 (2026-09-23)

S tier 작곡가의 수동 곡 중 아직 비교 영상이 없는 **96곡**이다(135 는 중복이라 뺐다). 발행된 것은 55곡이고
이 목록에는 들어 있지 않다. 한 배치는 3곡, 서브에이전트 둘을 동시에 돌린다.

구간 방식은 `references/01-selection.md` 의 표를 따른다.

| 표기 | 뜻 |
|---|---|
| `전곡` | 작품 전체가 600초 안. `WHOLE_WORK` |
| `악장` | 악장만 담긴 트랙이 있고 600초 안. `MOVEMENT` |
| `발췌` | 600초를 넘어 한 대목만. `EXCERPT`, `07-excerpt.md` |
| `낱곡` | 모음곡·선집이라 어느 곡을 쓸지 먼저 정해야 한다 |

위험 표시는 연주 3종을 못 모을 것 같은 곡이다. 1라운드에서 막힌 것은 전부
"유명도가 낮은 짧은 곡" 이었다.
