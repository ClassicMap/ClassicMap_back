# 비교 영상 S3 둘째 배치 검수 보고서

## 결론

6건을 적재했고 그중 3건을 발행했습니다.

| 곡 | 연주 3종 | 상태 |
|---|---|---|
| 베토벤 월광 소나타 3악장 Presto agitato | 리시차 / 폴리니 / 키신 | 발행 |
| 슈만 어린이의 정경 중 트로이메라이 | 랑랑 / 아르헤리치 / 백건우 | **미발행** |

월광 소나타는 같은 작품(piece 78)에 sector 를 하나 더 만든 것입니다.
1악장은 S3 첫 배치에서 이미 발행했습니다. 한 작품에 악장이 둘 붙은 첫 사례입니다.

## 트로이메라이에서 연주자를 한 번 바꿨습니다

처음 넣으려던 호로비츠는 다른 둘과 0.0900~**0.1149** 로, 한 쌍이 임계(0.11)를
넘었습니다. 끝점을 훑으니 142.9초에서 0.1087 까지 내려가 경계 문제가 일부
있었지만, 그래도 다른 쌍(0.068~0.082)보다 높은 채였습니다.
박쥐 서곡의 주빈 메타와 같은 기준으로 교체했고, 아르헤리치는 0.0793 으로
통과했습니다.

## 트로이메라이를 발행하지 않은 이유

적재는 됐지만 **의도한 곡이 아닌 곳에 붙었습니다.**

```
piece 135  "피아노 모음곡 <어린이의 정경>"   origin=manual  연주 0  part 0
piece 464  "Kinderszenen, op. 15"          origin=seed    연주 6  part 1
                                            ↑ musicbrainz_work a3f0f22c… 가 여기 있음
```

`piece_identifiers` 는 `(namespace, external_id)` 가 유일합니다. 그 MBID 가 이미
piece 464 에 붙어 있어 legacy 곡 135 에는 **붙일 수 없습니다.** 그래서 세 연주가
국제 시드 곡으로 해소됐습니다.

`202608050041` 이 푼 것과는 **다른 종류의 중복**입니다.

| | 그때 (달빛·라흐마니노프) | 이번 (트로이메라이) |
|---|---|---|
| 충돌 | piece_identifiers ↔ piece_parts | piece_identifiers ↔ piece_identifiers |
| 성격 | 동일성 진술 ↔ 포함 관계 | 동일성 진술 둘이 경쟁 |
| 해결 | 해소 규칙으로 우선순위를 정함 | 제약상 공존 불가 |

어느 곡을 정본으로 둘지는 화면에 무엇이 보여야 하는가의 문제입니다.
legacy 135 는 한국어 제목이 있고 국제 464 는 악장 part 를 갖고 있습니다.
비교 영상 시드에서 정할 일이 아니므로 적재된 3건은 클립을 만들지 않았고
발행되지 않은 상태로 남습니다.
