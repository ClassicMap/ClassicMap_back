# 비교 영상 S2 첫 배치 검수 보고서

## 결론

짧은 피아노 소품 3곡에 연주 3종씩, 총 9개 후보를 적재했습니다. 같은 방식으로 뽑았다가 검증에서 걸러낸 2곡 6건은 따로 보류했습니다.

**이 배치는 사람이 구간을 고르지 않았습니다.** 곡이 2~4분이라 작품 전체가 곧 비교 구간이므로, 정할 것은 "어디를 자를까"가 아니라 "음악이 실제로 어디서 시작하고 끝나는가"뿐입니다. 그 지점은 오디오에서 자동으로 찾았습니다.

| 곡 | 연주 3종 | 구간 |
|---|---|---|
| 쇼팽 연습곡 Op.10 No.12 "혁명" | 키신 / 조성진 / 폴리니 | 3–158 / 0–129 / 1–156초 |
| 쇼팽 녹턴 Op.9 No.2 | 랑랑 / 조성진 / 루빈스타인 | 0–234 / 4–242 / 2–236초 |
| 쇼팽 왈츠 Op.64 No.1 "강아지" | 랑랑 / 루빈스타인 / 키신 | 9–111 / 1–105 / 5–108초 |

## 음악 구간을 어떻게 찾았는가

박수와 음악은 음량으로 구분되지 않습니다. 둘 다 큽니다. 구분되는 것은 화성 구조입니다. 박수는 넓은 대역에 퍼진 잡음이고 음악은 배음이 정렬된 소리입니다.

1. **조성 성분만 남긴 에너지 곡선**을 만들어 임계를 넘는 구간을 찾습니다
2. **박수 구간을 따로 빼냅니다.** 넓은 대역에 고르게 퍼진 소리가 크게 들리는 곳입니다
3. 해설이나 인트로가 붙은 영상은 앞쪽에도 조성 성분이 잡히므로, **충분히 긴 구간 중 가장 이른 것**을 곡 본체로 봅니다
4. 조성 곡선은 평활화 때문에 시작이 뒤로 밀리므로, **원본 음량으로 첫 음을 되짚습니다**

### 검출기 검증

S1(2026-09-16)에서 사람이 스펙트로그램으로 직접 확인한 9개 지점을 정답으로 재었습니다.

| | 값 |
|---|---|
| 시작 오차 중앙값 | **0.16초** |
| 시작 오차 최대 | 1.08초 |
| 1초 이내 | **9건 중 8건** |

중간 단계의 실패도 남깁니다. 처음에는 "첫 구간"을 택해 7/9였으나 해설이 붙은 2건에서 16초·46초 빗나갔습니다. 이를 "가장 긴 구간"으로 바꾸자 오히려 2/9로 악화됐는데, 음악 안에도 여린 대목이 있어 곡이 토막나고 그중 가장 긴 조각이 곡 중간이었기 때문입니다. 최종 규칙은 그 둘의 절충입니다.

## 판정이 맞는지 어떻게 확인했는가

**같은 곡의 세 연주를 서로 정렬했습니다.** 같은 곡의 같은 구간이라면 연주가 달라도 화성 진행이 맞물립니다. 맞물리지 않으면 검출이 틀렸거나 애초에 같은 구간이 아닙니다.

적재한 3곡은 모든 쌍이 통과했습니다.

| 곡 | 정렬 비용 범위 |
|---|---|
| 혁명 에튀드 | 0.0434 ~ 0.0804 |
| 녹턴 Op.9 No.2 | 0.0545 ~ 0.0713 |
| 강아지 왈츠 | 0.0603 ~ 0.0754 |

## 걸러낸 2곡

쇼팽 즉흥환상곡과 리스트 사랑의 꿈 3번은 정렬 비용이 0.11~0.13으로 높아 뺐습니다. `held-candidates.json` 에 남겨 두었습니다.

| 쌍 | 비용 |
|---|---|
| 트리포노프 ↔ 루빈스타인 (즉흥환상곡) | 0.1309 |
| 시시킨 ↔ 루빈스타인 (즉흥환상곡) | 0.1108 |
| 임윤찬 ↔ 랑랑 (사랑의 꿈) | 0.1198 |

원인을 두 가지로 좁혀 확인했습니다.

**피치 차이가 아닙니다.** 옛 녹음은 전사 속도 때문에 피치가 틀어지기도 하고, 크로마는 절대 음고 기반이라 반음만 어긋나도 비용이 폭증합니다. 12방향으로 돌려 봤으나 어느 쪽으로도 나아지지 않았습니다.

**검출 오류도 아닙니다.** 구간을 앞·중간·뒤로 나눠 재니 전 구간이 어긋났고, 특히 중간이 0.21로 가장 나빴습니다. 경계가 틀렸다면 한쪽 끝만 어긋납니다.

남는 설명은 **연주 구조 자체가 다르다**는 것입니다. 즉흥환상곡은 중간부 반복 여부가, 사랑의 꿈은 카덴차 처리가 연주마다 다릅니다. 전곡을 구간으로 삼는 방식의 한계입니다.

파일럿 15건이 이 문제를 겪지 않은 것은 대상이 40~115초짜리여서 반복이 없었기 때문입니다. S2 대상(1~8분)부터는 반복이 있는 곡이 섞이므로, 이 검증을 매 배치에 넣어야 합니다.
