# 고전·근현대 작곡가 작품 목록 (2026-11-12)

S·A 등급인데 작곡가 화면에 작품이 3~4개뿐인 작곡가의 작품 목록을 채워요. 리하르트 슈트라우스
(`../richard-strauss-catalog-2026-11-11/`)와 같은 방식이에요. 작품은 작곡가 폴더의 `works.tsv` 에 손으로 고르고,
곡은 MusicBrainz parts 관계에서 가져와요. `build.py` 하나를 작곡가 모두에게 써요.

| 작곡가 | composer_id | 마이그레이션 | 보이는 작품 (전 → 후) | 새 작품 | 곡·악장 |
|---|---:|---|---:|---:|---:|
| 무치오 클레멘티 | 25 | `202611120201_add_clementi_catalog.sql` | 3 → 41 | 39 | 318 |
| 요한 슈타미츠 | 24 | `202611120202_add_johann_stamitz_catalog.sql` | 3 → 24 | 21 | 127 |

보이는 작품은 작곡가 목록 최상위 기준이에요(숨김 없음, 다른 묶음의 곡으로 이어지지 않음).

## 왜 손으로 골랐나

4차 자동 규칙(`../catalog-wave4-2026-10-12/auto/auto_catalog.py`)은 MusicBrainz 관계 때문에 주요 작품을 빼고 잡음을 넣어요.
또 MusicBrainz 작곡가별 작품 목록에는 헌정·편곡 관계만 있는 남의 곡이 섞여 있어요. 예를 들어 클레멘티 목록에 존 필드의
「3 Piano Sonatas, op. 1」, 쇤베르크 목록에 베르크의 「Drei Orchesterstücke, op. 6」, 리게티 목록에 Touchard 의
「Étude n° 5」가 있어요. `build.py` 는 고른 work 의 composer 관계가 그 작곡가인지 확인하고, 아니면 멈춰요.

## 공통 규칙

- 같은 이름 work 가 여럿이면 편곡(arrangement) 관계의 원본이고 편곡자가 없는 쪽을 써요.
- 오페라·오라토리오·칸타타 같은 큰 작품은 본보기처럼 곡 없이 둬요.
- 곡 이름은 MusicBrainz 원제에서 번호·작품번호·따옴표를 떼요. 악장 첫머리의 갈래어만 운영 관례대로 우리말로 옮겨요
  (피날레·미뉴에트·미뉴에트와 트리오·론도·스케르초·전주곡·서곡·서주·주제·변주·가보트·지그 등).
- 세트 안 곡은 「피아노 소나타 2번 C장조」 꼴이에요. 번호는 그 작품번호 안의 번호예요(하이든 「현악 4중주 Op. 76」과 같은 꼴).
- 세트 안 곡이 다시 악장으로 나뉘면 두 겹까지 붙이고 그 아래는 버려요.
- 손으로 정한 곡 이름과 곡에 이을 기존 작품은 작곡가 폴더의 `parts_ko.tsv` 에 적어요.
- 기존 작품은 제목·설명·링크·장르를 그대로 두고 MBID 와 곡만 더해요.
- 장르·형식은 `piece_forms` 짝대로 넣고(`build.py` 가 확인), 비어 있을 때만 채워요.

## 무치오 클레멘티 (`clementi/`)

- 피아노 소나타 묶음: Op. 1·1a·2·7·8·9·10·12·13·23·24·25·33·34(소나타 2곡 + 카프리치오 2곡)·37·40·50.
- 낱개 작품: 피아노 소나타 Op. 11-1·16 「사냥」·20·26·41·46·WoO 3·13·14, 토카타 Op. 11-2, 카프리치오 Op. 17,
  「2개의 카프리치오」 Op. 47, 「음악적 특성」 Op. 19, 「달빛 아래서」 환상곡과 변주곡 Op. 48, 「Batti, batti」 변주곡 WoO 10,
  「12개의 몬페리나」 Op. 49, 교향곡 Op. 18(2곡)·1~4번(WoO 32~35), 피아노 협주곡 C장조 WoO 12.
- 기존 작품
  - 113 「소나티네 Op. 36」에 6곡과 악장을 붙여요.
  - 114 「그라두스 아드 파르나숨」은 MusicBrainz 에 곡이 권마다 하나뿐이라 MBID 만 이어요.
  - 115 「버림받은 디도」는 새 「피아노 소나타 Op. 50」의 3번 곡으로 이어요(MBID 같음). 그래서 작곡가 목록 최상위에서는
    Op. 50 안으로 들어가요(베토벤 「월광」 = Op. 27 선례). 「처음 듣는다면」 카드는 숨김 여부만 보므로 그대로 보여요.
- Op. 2·13 은 피아노 독주 소나타만 넣어서(Op. 2 의 2·4·6번, Op. 13 의 4~6번) 곡 이름에 원래 번호를 써요.
  Op. 1a 는 위키백과대로 소나타 4곡만 넣었어요(5번은 푸가, 6번은 이중주).
- 연도는 위키백과 작품 목록의 출판 연도예요. 작곡 연도가 따로 적힌 WoO 13·14 만 작곡 연도예요. 모르는 것은 비웠어요.
- 뺀 것
  - 바이올린·플루트·첼로가 붙는 소나타와 3중주 묶음(Op. 2 의 1·3·5번, Op. 3~6·15·21·22·27~29·32·35 등): MusicBrainz 에 없어요.
  - 피아노 연탄·두 대 피아노 이중주(Op. 3·6·14, WoO 24~28): MusicBrainz 에 곡 정보가 없어요.
  - 소나티네 Op. 37·38: MusicBrainz 와 위키백과의 조성·번호가 맞지 않아요.
  - 「피아노 연주법 입문」 Op. 42, 낱개 몬페리나 WoO 15~20·타란텔라·론도 같은 소품, 「14개의 여러 나라 선율」.
  - 모차르트·하이든 교향곡 편곡, 「Sonata in E-flat major, op. 44, C 178」(번호가 그라두스와 겹치는 정체 모를 work).

## 요한 슈타미츠 (`stamitz/`)

- 관현악 3중주 Op. 1(6곡)·Op. 4-3·Op. 5-3, 교향곡 Op. 3-1·3·4·6, Op. 4-1·2(「신포니아 파스토랄레」)·4·6, Op. 11-3,
  「만하임」 2·3번, 4성부 신포니아 D장조, 플루트 협주곡 C·G장조, 비올라 협주곡 G장조, 바이올린 협주곡 C장조,
  바이올린 소나타 Op. 6(6곡), 무반주 바이올린을 위한 2개의 디베르티멘토.
- 기존 세 곡(클라리넷 협주곡 110, 신포니아 D장조 Op. 3-2 111, 트럼펫 협주곡 112)에는 악장을 붙이고, 111 에는 MBID 도 이어요(작품번호로 맞춤).
- 교향곡에 전곡 번호가 없어 같은 조성이 여럿이라 작품번호를 제목 끝에 넣었어요(하이든 「현악 3중주 E♭장조 Hob. V:4」 꼴).
- 연도는 확실한 것이 없어 비웠어요.
- 뺀 것
  - 아들 카를 슈타미츠 곡으로 보이는 것: 클라리넷·바순 협주곡 B♭장조, 오보에 4중주 E♭장조, 비올라 소나타 B♭장조.
    위키백과의 요한 슈타미츠 협주곡 목록(바이올린·비올라 2·하프시코드 2·플루트 12·오보에·트럼펫·클라리넷)에 이중 협주곡이 없고,
    나머지 둘도 요한의 작품이라는 출처를 찾지 못했어요.
  - 오르간 협주곡 1~4번: 위키백과에는 건반 협주곡이 하프시코드 2곡뿐이에요.
  - 「만하임 1번」: 위키백과는 앙투안 마오의 곡으로 봐요. 악장이 같은 「Symphony in G major」도 같은 곡으로 보고 뺐어요.
  - 출처를 알 수 없는 「Symphonie in Es-Dur」·「Sinfonia in G major」(Op. 3-3 과 악장이 같아 겹칠 수 있음).
  - 플루트 협주곡 D장조 2곡: 둘을 구별할 번호가 없어요.
  - 다른 사람이 편곡한 「Caprice」.
- MusicBrainz 에 확인할 만한 작품이 적어 보이는 작품이 24개에서 그쳤어요(교향곡 58곡 중 대부분이 MusicBrainz 에 없어요).

## 다시 만들기

`seed_pipeline` 에서, 작곡가마다(`clementi` 25, `stamitz` 24):

1. `../catalog-wave6-2026-11-10/tools/dump.sh <덤프>`: 운영 읽기 덤프
2. `uv run python curation/composer-catalog-2026-11-12/build.py --composer <slug> --out <W>`: `catalog.json`·`seed_map.json`(빈 목록)·`genres.sql`
3. `uv run python curation/catalog-wave4-2026-10-12/gen_catalog.py --composer-id <id> --slug <slug> --catalog <W>/catalog.json --pieces <덤프>/pieces.tsv --taken <덤프>/all_mbids_taken.tsv --seed-map <W>/seed_map.json --out <W>/catalog.sql`
4. 마이그레이션 = 머리 설명 + `catalog.sql` + `genres.sql`

대상 작곡가는 seed 작품이 없어 숨길 것도 없어요. MusicBrainz 요청은 `../catalog-wave6-2026-11-10/tools/fetch.py`(캐시 `CM_FETCH_CACHE`, 1.1초 간격)로 보내요.

## 시험

운영 카탈로그 읽기 덤프를 올린 시험 DB(`devdb.sh`, cm-cat-b-mysql)에 마이그레이션을 파일마다 한 트랜잭션으로 두 번 넣었어요.
두 번째에 바뀌는 행이 없고, `piece_forms.genre` 와 `pieces.genre` 어긋남 0, 새 작품 장르 빈칸 0이에요.
기존 작품의 제목·설명·링크·장르, 비교 구간, 「처음 듣는다면」 카드, 영화 큐는 그대로이고 바뀐 것은 MBID 추가뿐이에요.
다른 작곡가의 작품·part 는 바뀌지 않아요.
