- `SPEC.md`: 에이전트에게 준 작업 명세예요. 1차 명세에 운영 기존 작품 중 대목 작품(「오페라 <X> 중 "Y"」)과 여러 작품을 한데 묶은 작품을 다루는 규칙을 더했어요.
- `<작곡가>/catalog.json`: 넣는 작품만 담았어요. `<작곡가>/report.md`: 운영 기존 작품 대응, 뺀 것과 까닭, 애매했던 판단, 직접 옮긴 우리말 이름, 위키백과 대조 결과예요.
  보고서 대부분은 에이전트가 메시지로 보낸 본문을 옮긴 것이에요(에이전트 쪽에서 보고서 파일 쓰기가 막혀 있었어요).
- 운영 작품번호를 바로잡은 곳 3개는 해당 마이그레이션 끝에 손으로 더했어요: 라모 47(RCT 3 → RCT 2), J.C. 바흐 108(W.C 34 → W.C 43), 스트라빈스키 312(K. 51 → K. 52).
- 프랑크 181 「생명의 양식」은 <3성 미사> 5악장과 MBID 가 같아, 리드가 catalog.json 에서 그 part 의 existingPieceId 로 이었어요.

로컬 dev(운영 카탈로그 덤프)에서 백엔드를 띄워 25개 마이그레이션이 3.7초에 적용되고, 한 번 더 돌려도 바뀌는 행이 없는 것을 확인했어요.
