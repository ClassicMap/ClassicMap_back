# 교차 정렬과 어긋남 진단

세 연주가 같은 음악인지 재는 일이다. **이 단계가 배치의 안전망이다.**
지금까지 모든 배치에서 최소 한 건씩 걸러냈다.

## 어떻게 재는가

구간의 화성 윤곽(`chroma_cens`)을 뽑아 DTW 로 늘여 맞추고, 남는 거리를 경로
길이로 나눈다. 길이로 나누기 때문에 **템포가 달라도 비용이 커지지 않는다.**

```python
distance, path = librosa.sequence.dtw(X=a, Y=b, metric="cosine", subseq=False)
cost = distance[-1, -1] / len(path)
```

`subseq=False` 다. 시작점을 고정해서 잰다. 부분 일치를 허용하면 비슷한 다른
대목에 붙어 값이 나빠진다.

## 임계

**0.11** 이다. 통과한 배치는 대개 **0.04~0.09** 에 모인다.

임계 아래라도 **같은 곡의 다른 쌍보다 눈에 띄게 높으면 진단한다.**
0.10 대에서 통과시킨 뒤 판본이 다른 것으로 드러난 적이 여러 번 있다.

```
박쥐 서곡   카라얀 ↔ 클라이버 0.0583   카라얀 ↔ 메타 0.0964  ← 이 차이를 본다
```

## 길이로는 판정할 수 없다

| 곡 | 길이 편차 | 비용 | 판정 |
|---|---|---|---|
| 빗방울 전주곡 | 1.34배 | 0.066~0.074 | 통과 |
| 아라베스크 1번 | 1.35배 | 0.049~0.066 | 통과 |
| 월광 1악장 | 1.24배 | 0.044~0.049 | 통과 |

반대로 길이가 비슷해도 판본이 다르면 걸린다. **화성 진행만이 근거다.**

편성이 달라도 통과한다. 타이스 명상곡은 세 연주의 반주 편성이 서로 달랐는데
(피아노 / 관현악) 0.057~0.079 였다. 성악도 같다. 가사와 발음은 chroma 에 잡히지
않는다.

## 어긋남의 네 가지 모양

임계를 넘으면 `run_diagnose.py` 로 경계를 훑는다. **곡선의 모양이 원인을 말한다.**

### 1. 여러 쌍이 함께 내려감 → 경계 오류

```
쌍                 처음     274.7초로 보정
아슈케나지 ↔ 길렐스  0.1106  →  0.0984
아슈케나지 ↔ 레비트  0.0652  →  0.0471   ← 이 쌍도 함께 내려갔다
```

검출이 경계를 잘못 잡은 것이다. **값을 고쳐 쓴다.**
두 쌍이 함께 움직이는 것이 근거다. 연주가 다르면 한 쌍만 움직인다.

### 2. 어디로 옮겨도 평평함 → 판본·연주가 다름

```
끝(초)   565.5  568.5  571.5  574.5 ... 601.5
비용     0.106  0.108  0.109  0.110      0.110
```

경계 문제가 아니다. **연주를 교체한다.**
박쥐 서곡(메타), 발라드 1번(짐머만)이 이랬다.

### 3. 조금 내려가다 멈춤 → 연주가 다름

트로이메라이(호로비츠)가 0.1149 → 0.1087 까지만 내려갔다. 경계도 조금 문제였지만
그것만으로 설명되지 않는다. **교체한다.**

### 4. 특정 지점에서만 뚝 떨어짐 → DTW 경로 불안정

```
끝(초)   179.3  181.8  184.3  186.8  189.3 ... 199.3
비용     0.119  0.119  0.082  0.118  0.118      0.082
```

어느 경계에서든 0.08 이 나온다는 것은 같은 곡이라는 뜻이다. 다만 경로가 두
갈래로 갈리고 경계가 조금 달라지면 다른 쪽으로 빠진다. 라이브 연주의 늘임이
심하면 이렇게 된다.

**구간을 억지로 맞추면 통과하지만 그 값이 음악적 경계가 아니므로 교체한다.**
네순 도르마(플로레스)가 이랬다.

### 5. 세 쌍이 모두 넘음 → 곡이 연주마다 구조가 다름

```
피레스 ↔ 굴드      0.1217
피레스 ↔ 호로비츠   0.1177
굴드 ↔ 호로비츠     0.1160
```

한 연주가 아니라 **곡이 문제다.** 어느 하나를 바꿔도 낫지 않는다.

비창 1악장이 이랬다. 제시부 반복이 있고 연주자마다 반복 여부가 달라 구조가
갈린다. 굴드는 357초, 호로비츠는 500초였다. 진단해 보면 경계도 이조도 아니고
경계를 훑어도 평평하다.

**이런 곡은 그 구간을 포기한다.** 반복이 없는 다른 악장으로 가거나 다른 곡을
고른다. 비창은 2·3악장으로 갔다.

반복 구조가 갈리는 곡은 미리 의심한다. 고전 소나타의 1악장(제시부 반복),
쇼팽 즉흥환상곡, 리스트 사랑의 꿈이 그랬다.

## 이조

성악에서 한 번씩 나온다. 연주자가 음역에 맞춰 조를 옮기기 때문이다.
크로마를 12방향으로 돌려 본다. 특정 회전에서 뚝 떨어지면 이조다.

```
0반음 0.118   1반음 0.306   2반음 0.294 ...   ← 0이 최선이면 조성은 같다
```

## 곡 맨 앞은 취약하다

비용이 낮아도 틀릴 수 있다. 앞쪽 문맥이 없어 DTW 가 붙잡을 곳이 없기 때문이다.
라 캄파넬라 도입을 0.0616 으로 통과시켰는데 6.5초 틀렸던 적이 있다.

반복 음형은 원리적으로 위치를 특정할 수 없다. 그 곡의 5.0~8.0초 구간은 비용이
0.038~0.051 로 평평했다. **도입부를 따로 뽑을 때는 "음악 시작점 고정 + 길이
탐색"으로 다룬다.**

## 문맥을 포함해 재면 정확해진다

구간 앞뒤로 ±20초를 포함해 정렬하면 경계가 더 정확해진다. 라흐 3번 검증에서
확인했다. `run_verify.py` 는 구간만으로 재지만, 경계를 다툴 때는 문맥을 넣어
본다.
